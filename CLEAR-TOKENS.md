# ⚡ SOLUTION IMMÉDIATE - Nettoyer les tokens

## Le problème
Le frontend a un ancien token JWT qui référence un utilisateur supprimé.

## ✅ SOLUTION (30 secondes)

### Dans le navigateur :

1. **Ouvrir la console** (F12)

2. **Copier-coller cette commande** :
```javascript
localStorage.clear();
sessionStorage.clear();
location.reload();
```

3. **Appuyez sur Entrée**

4. **Reconnectez-vous** avec `gestionnaire@test.com` / `Gestionnaire123!`

5. **Testez la soumission de structure** ✅

---

## C'est tout ! Le problème est résolu.
